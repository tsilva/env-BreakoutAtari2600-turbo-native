# Delegate cross-provider parity to TurboBench

Cross-provider comparison belongs to TurboBench. This repository keeps tests
for its own deterministic and cross-platform behavior, while immutable
TurboBench profiles define the authority, workload, checks, quick workload, and
receipt format.

Original Stable Retro is the authority for direct Breakout comparison. Stable
Retro Turbo remains a compatible candidate provider, not an authority selected
or adapted by this repository.
